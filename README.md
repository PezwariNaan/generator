# Generator

A Rust-based wordlist and token extraction tool designed for reconnaissance, content discovery, and security research.

The goal of this project is to extract potentially interesting words, identifiers, paths, and application-specific terminology from web pages while filtering out common noise generated by modern JavaScript-heavy applications.

This project is primarily a learning exercise in:

* Rust
* Text processing
* NLP-inspired feature extraction
* Reconnaissance tooling
* Software architecture and trait-based design

---

## Features

### Token Extraction

Extracts candidate words from HTML content.

Examples:

```text
admin
dashboard
graphql
oauth
customer
internal
```

---

### Normalisation

Tokens are normalised before processing.

Current filtering includes:

* Lowercasing
* Length limits
* Numeric-only removal
* Hexadecimal string removal
* Symbol-only removal
* Custom exclusion list support

---

### Token Splitting

Supports extraction from common identifier formats.

#### Snake Case

```text
admin_dashboard
```

becomes:

```text
admin
dashboard
```

#### Kebab Case

```text
user-profile
```

becomes:

```text
user
profile
```

#### Camel Case

```text
AdminDashboard
```

becomes:

```text
admin
dashboard
```

---

### Feature Extraction

Each token receives a collection of scoring metrics.

Current metrics include:

| Feature          | Description                                          |
| ---------------- | ---------------------------------------------------- |
| Entropy          | Shannon entropy of the token                         |
| Vowel Ratio      | Percentage of characters that are vowels             |
| Digit Ratio      | Percentage of characters that are numeric            |
| Dictionary Match | Whether the token appears in the supplied dictionary |
| Occurrence Count | Number of times the token appears                    |

Example:

```rust
Score {
    entropy: 3.87,
    vowel_ratio: 0.33,
    digit_ratio: 0.0,
    dictionary_match: true,
    occurrence: 2,
}
```

---

### Dictionary Support

Dictionary words are loaded at compile time using:

```rust
include_str!()
```

This allows efficient lookups without runtime file handling.

Current dictionaries:

```text
data/
├── words_alpha.txt
└── exclude_keywords.txt
```

## Architecture

The project uses trait-based abstractions to reduce coupling between components.

### Traits

#### Splitter

```rust
pub trait Splitter {
    fn split(&self, input: &str) -> Vec<String>;
}
```

Responsible for splitting identifiers into component words.

---

#### Scorer

```rust
pub trait Scorer {
    fn entropy(&self, token: &str) -> f64;
    fn vowels(&self, token: &str) -> f64;
    fn digits(&self, token: &str) -> f64;
}
```

Responsible for calculating token metrics.

## Motivation

Modern web applications contain enormous amounts of generated JavaScript, bundled dependencies, and framework code.

Traditional wordlist generation tools often produce large amounts of noise.

This project aims to explore whether lightweight NLP-inspired techniques and feature extraction can improve the quality of generated recon wordlists while serving as a practical Rust learning project.
